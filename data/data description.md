# Описание данных

## Таблица `players`

Содержит данные об игроках и их статистике в матчах.

| Поле                   | Описание                                                                           |
| ---------------------- | ---------------------------------------------------------------------------------- |
| `Match_id`             | Идентификатор матча                                                                |
| `Player_slot`          | Слот игрока в матче                                                                |
| `Steam_id`             | Идентификатор аккаунта игрока                                                      |
| `Personaname`          | Имя игрока                                                                         |
| `Assists`              | Количество ассистов в матче (помощь в убийстве)                                    |
| `Deaths`               | Количество смертей в матче                                                         |
| `Denies`               | Количество отказов от матча                                                        |
| `Gold_per_min`         | Количество золота, получаемого игроком за минуту матча                             |
| `Hero_id`              | Идентификатор героя игрока                                                         |
| `Item_0` – `Item_5`    | Идентификаторы шести предметов игрока                                              |
| `Kills`                | Количество убийств в матче                                                         |
| `Xp_per_min`           | Количество опыта, получаемого за минуту матча                                      |
| `isRadiant`            | Принадлежность игрока к фракции Radiant или Dire                                   |
| `Win`                  | Результат матча для игрока: 1 — победа, 0 — поражение                              |
| `Kills_per_min`        | Количество убийств за минуту матча                                                 |
| `Last_hits_per_min`    | Количество последних ударов по крипам за минуту матча (влияет на получение золота) |
| `Hero_damage_per_min`  | Средний урон, наносимый героями за минуту                                          |
| `Hero_healing_per_min` | Среднее количество лечения за минуту                                               |
| `Tower_damage_per_min` | Урон, наносимый башням за минуту                                                   |

## Таблица `matches`

Содержит данные о прошедших матчах между игроками.

| Поле               | Описание                                                             |
| ------------------ | -------------------------------------------------------------------- |
| `Match_id`         | Идентификатор матча                                                  |
| `Duration`         | Длительность матча в секундах                                        |
| `First_blood_time` | Время до первого убийства                                            |
| `Radiant_win`      | Результат матча: 1 — победа фракции Radiant, 0 — победа фракции Dire |
| `Region`           | Идентификатор региона, в котором проходил матч                       |

## Таблица `heroes`

Содержит данные о героях, доступных в игре.

| Поле                | Описание                                       |
| ------------------- | ---------------------------------------------- |
| `Id`                | Идентификатор героя                            |
| `Localized_name`    | Имя героя                                      |
| `Attack_type`       | Тип атаки героя                                |
| `Primary_attr`      | Основной атрибут героя                         |
| `Roles`             | Роли героя                                     |
| `Base_health`       | Базовое здоровье                               |
| `Base_health_regen` | Базовая регенерация здоровья                   |
| `Base_mana`         | Базовый запас маны                             |
| `Base_mana_regen`   | Базовая регенерация маны                       |
| `Base_armor`        | Базовая броня                                  |
| `Base_mr`           | Базовое сопротивление магии (Magic Resistance) |
| `Base_attack_min`   | Минимальный базовый урон атаки                 |
| `Base_attack_max`   | Максимальный базовый урон атаки                |
| `Base_str`          | Базовая сила                                   |
| `Base_agi`          | Базовая ловкость                               |
| `Base_int`          | Базовый интеллект                              |
| `Str_gain`          | Прирост силы с каждым уровнем                  |
| `Agi_gain`          | Прирост ловкости с каждым уровнем              |
| `Int_gain`          | Прирост интеллекта с каждым уровнем            |
| `Attack_range`      | Дальность атаки                                |
| `Projectile_speed`  | Скорость полёта снаряда                        |
| `Attack_rate`       | Скорость атаки                                 |
| `Base_attack_time`  | Базовое время атаки                            |
| `Attack_point`      | Время подготовки атаки                         |
| `Move_speed`        | Скорость передвижения                          |
| `Turn_rate`         | Скорость поворота                              |
| `Cm_enabled`        | Доступность героя в капитанском режиме         |
| `Legs`              | Количество ног                                 |
| `Day_vision`        | Радиус видимости днём                          |
| `Night_vision`      | Радиус видимости ночью                         |
